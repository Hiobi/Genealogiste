# Signaler un problème de sécurité

Ne publiez ni secret, ni donnée généalogique réelle, ni reproduction contenant des données personnelles
dans une issue publique. Utilisez [le signalement privé GitHub](https://github.com/Hiobi/Genealogiste/security/advisories/new).
Fournissez la version, les étapes sur données fictives et l’impact attendu. Les correctifs de sécurité
portent sur la dernière version publiée ; mettez à jour le plugin et redémarrez le serveur MCP.

Si un secret a été publié : révoquez-le immédiatement auprès du fournisseur, puis signalez son emplacement
sans recopier sa valeur. Effacer un fichier ou réécrire Git ne révoque pas un identifiant et ne retire pas les
copies déjà téléchargées.

Le dépôt contient des fixtures synthétiques. Les arbres, médias, journaux, notes et sauvegardes des
utilisateurs doivent rester privés, dans des répertoires distincts du code. Voir [le guide de production](docs/production.md).
