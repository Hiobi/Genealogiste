# Latin des registres et abréviations

## Formulaires types
- **Baptême** : *Anno Domini … die … mensis … baptizatus est (baptizata est) Joannes, filius legitimus
  Petri Martin et Mariae Dupont conjugum, natus heri. Patrinus fuit … matrina vero …*
- **Mariage** : *… publicatis tribus bannis … nullo detecto impedimento … in matrimonium conjunxi Joannem
  Martin … et Annam Roy … praesentibus testibus …* ; *dispensatione obtenta in tertio gradu consanguinitatis*.
- **Sépulture** : *… obiit … aetatis suae circiter … annorum … sepultus est in cimiterio (in ecclesia) …*
